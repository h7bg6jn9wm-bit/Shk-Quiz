# SHK Störungs-Quiz – 3 Modi

Mobile-first SHK-Fehlerquiz mit drei Schwierigkeitsstufen:

- Azubi-Modus
- Geselle-Modus
- Meister-Modus

Jeder Modus spielt genau 20 Fragen. Die Antwortpositionen werden zufällig gemischt. Über „← Menü“ kommt man jederzeit zurück zur Modusauswahl.

Offline/PWA-fähig.
